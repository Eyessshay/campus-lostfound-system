# Campus Lost & Found System

## Project Overview

This is a beginner-friendly PHP + MySQL campus lost and found system.

The project is a university course assignment.

Main features:

* User register/login
* Session authentication
* Publish lost/found items
* Upload images
* Search items
* Admin management

---

# Tech Stack

Frontend:

* HTML
* CSS
* JavaScript
* jQuery

Backend:

* PHP7 procedural programming
* Apache

Database:

* MySQL

Environment:

* AppServ

# Coding Rules

* Use procedural PHP
* Use mysqli
* Do NOT use PDO
* Do NOT use frameworks
* Do NOT use Laravel
* Do NOT use Composer
* Keep code beginner-friendly
* Use Session for login
* Use password_hash()
* Use move_uploaded_file()

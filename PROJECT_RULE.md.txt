# Campus Lost & Found System

## Project Overview

This is a PHP + MySQL based campus lost and found system.

The project is a simple course project for web development learning.

Main features:

- User register/login
- Session authentication
- Publish lost/found items
- Upload item images
- Search items
- Edit/delete own posts
- Admin management

# Coding Rules

- Use procedural PHP
- Use mysqli instead of PDO
- Do not use frameworks
- Keep code simple for beginners
- Use separate PHP files for each function
- Use Session for login authentication
- Use password_hash() for passwords
- Use move_uploaded_file() for image upload

---

# Database Rules

Database name:
lostfound

Main tables:
- users
- lost_items
- categories
- messages

Relationships:
- One user can publish many items
- One category can contain many items
- One item can contain many messages
